Крутая замена word. Можно писать верстку в любом текстовом редакторе. Удобно для курсовых, дипломных и больших проектов

Для компиляции проекта:

```bash
typst watch index.typ index.pdf --root .
```

Потом открыть skim (только для макос). Обновляет документ при новой компиляции (надо галочку в настройках skim поставить)
```bash
open -a Skim index.pdf
```
